# Ассемблер УВМ. Вариант №28

## Этап 1. Промежуточное представление

Программа читает команды из JSON-файла и преобразует их в список словарей с полями A, B, C и D.

Поддерживаются четыре команды:

- load: загрузка константы C в регистр B, A=1
- read: чтение значения из памяти, A=5
- write: запись значения в память, A=0
- not: побитовое НЕ, A=15

## Функции

- mask(n): создание битовой маски.
- check_value(): проверка значения поля.
- asm_const(): загрузка константы.
- asm_read(): чтение из памяти.
- asm_write(): запись в память.
- asm_not(): побитовое НЕ.
- asm(): обработка списка команд.
- main(): чтение JSON и запуск программы.

## Запуск

```bash
python -m src.main --input tests/specification.json --output result.bin --test
```

Параметры:
- --input: путь к JSON-файлу
- --output: путь к будущему бинарному файлу
- --test: вывод внутреннего представления

На первом этапе бинарный файл не создаётся.

## Проверка

python -m tests.test_assembler

## Этап 2. Формирование машинного кода

Во втором этапе реализовано преобразование команд из промежуточного представления в машинный код.

Для каждой команды используются поля A, B, C и D, расположенные на определённых битовых позициях. Поля объединяются побитовыми сдвигами и операцией ИЛИ.

Все команды занимают 3 байта. Для записи используется порядок Little-Endian.

Добавлены функции:

- encode_const(): кодирование загрузки константы.
- encode_read(): кодирование чтения из памяти.
- encode_write(): кодирование записи в память.
- encode_not(): кодирование побитового НЕ.
- asm_bytes(): сборка машинного кода программы.

Пример запуска:

python -m src.main --input tests/specification.json --output result.bin --test

После запуска создаётся двоичный файл result.bin.
В тестовом режиме выводятся поля команд, последовательности байтов, количество команд и размер файла.
Все четыре команды проверяются по байтовым последовательностям из спецификации варианта №28.

Запуск тестов:
python -m tests.test_assembler
