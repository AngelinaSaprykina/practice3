# Ассемблер УВМ. Вариант №28

## Этап 1. Промежуточное представление

Программа читает команды из JSON-файла и преобразует их в список словарей с полями A, B, C и D.

Поддерживаются четыре команды:

- load: загрузка константы C в регистр B, A=1
- read: чтение значения из памяти, A=5
- write: запись значения в память, A=0
- not: побитовое НЕ, A=15

## Функции

- mask(n): создание битовой маски.
- check_value(): проверка значения поля.
- asm_const(): загрузка константы.
- asm_read(): чтение из памяти.
- asm_write(): запись в память.
- asm_not(): побитовое НЕ.
- asm(): обработка списка команд.
- main(): чтение JSON и запуск программы.

## Запуск

```bash
python -m src.main --input tests/specification.json --output result.bin --test
```

Параметры:
- --input: путь к JSON-файлу
- --output: путь к будущему бинарному файлу
- --test: вывод внутреннего представления

На первом этапе бинарный файл не создаётся.
